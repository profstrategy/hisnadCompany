# Hisnad Real Estate & Agriculture Management System

A scalable web application designed to manage real estate and agricultural land investments, bookings, and client interactions through a centralized platform.
The system supports secure user onboarding, role-based dashboards, payment processing, and data-driven analytics for both administrators and clients.

## Features

- Authentication & User Management
  - Secure authentication using NextAuth with Prisma adapter
  - Role-based access for administrators and clients
  - Email verification and onboarding workflows
    
- Admin Dashboard
  - Land and package listing management
  - Real-time land availability and viewing
  - User data management
  - Platform analytics and performance insights
    
- Client Dashboard
  - Investment and revenue tracking
  - Performance metrics and activity insights
  - Date range filtering for analytics
    
- Payments & Onboarding
  - Secure user registration and email verification
  - Integrated payment processing
  - Seamless onboarding experience

- Package & Land Management
  - Active package listings
  - Detailed package views
  - Real estate and agricultural land selection
  - 
## Tech Stack
- Next.js – Frontend framework
- TypeScript – Type-safe development
- Prisma ORM – Database access and querying
- Supabase – Database and authentication services
- Cloudinary – Image storage and optimization
- Zustand – State management and data persistence
- Shadcn UI – Reusable UI components
- RESTful APIs – Backend integrations

## Project Structure
- app/          # Next.js app directory
- api/          # API services and type definitions
- components/   # Reusable UI components
- lib/          # Utility functions and constants
- public/       # Static assets
- styles/       # Global styles and Tailwind CSS


## Purpose
This project was built to streamline the management of real estate and agricultural investments by providing a secure, scalable, and data-driven platform that improves operational efficiency and enhances transparency for both administrators and clients.
